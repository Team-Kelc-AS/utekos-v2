# V2 overtar sporing – gjennomføringsplan

Oppdatert 10. oktober 2026. `utekos-headless` er pensjonert og skal aldri publiseres igjen. V2 overtar butikkfronten; `utekos-tracking-backend` eier kanonisk innsamling, Shopify-webhooks og provider-outbox. Brukeren har uttrykkelig godkjent workers, køer, cron og publisering. Tidligere Brand Studio-begrensning er opphevet.

1. **Kilde og eierskap – utført.** Backend main `bcb7ddffd0c7a71fa5e19fa172c8951349229c07` er i produksjon. Eksisterende storefrontprosjekt er koblet til `Team-Kelc-AS/utekos-v2` etter brukerens GitHub-tilgangsbekreftelse. Ingen ny headless-release.
2. **Hendelser – implementert og testet.** Aktiv søkesporing er fjernet, også fra web-GTM live 174. Variantvalg, produktlenke, pris, kurv og sporingspayload følger samme variant. Dun Lead speiler bare serverkvittering. Checkout v4 lagres varig når completion kommer før betalingswebhook; senere promotering krever autoritativ betalt ledger.
3. **Worker-overtakelse – deployet og runtime-verifisert.** Gamle storefront-crons ble deaktivert før backend-release. Backend har ni cron-planer, aktiv ingress/køpublisering og privat køtrigger. Redis, database og tabellprivilegier er kontrollert. En no-op-melding er korrelert med privat konsumentlogg. Gamle deploymenter beholdes for historiske kømeldinger; unrelated LaunchGuard-workflows er ikke slettet.
4. **Microsoft-gjenoppretting – levert.** Tre manglende Purchase innen syvdagersfristen er opprettet fra uendret paid-ledger, samtykke, ID og tidspunkt. Alle tre har HTTP 200, eventsReceived=1, null valideringsfeil/varsler. Fire eldre hendelser er utløpt og redateres ikke. Ingen delte mål, kampanjer eller budsjetter er endret.
5. **V2-trafikkrelease – deployet; produksjonsreise under retting.** V2 f12bbae er READY på butikkdomenene. Positiv produksjons-OIDC og rå Shopify-HMAC er verifisert; gyldig development-token er avvist. Chrome viste riktig variant, pris, kurv og Meta/Microsoft-mottak for PageView/AddToCart/ViewCart. Testen avdekket checkout 409, feed 404 og Google audience-formatfeil. Rettelser bygges, publiseres med pnpm run sync og kontrolleres på domenene. Safari, Klarna og naturlig kjøp/refusjon må bevise completion, deduplisering og attribusjon separat.
